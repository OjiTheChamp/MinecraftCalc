# ⛏ Crafted Calc

A Minecraft-themed scientific calculator built by **oji the champ**.

## Features
- Green CRT-style display
- Memory section (MC, MR, MS, M+, M−)
- Scientific functions (sin, cos, tan, inverses, log, ln, √, x², n!, π, e, and more)
- DEG / RAD toggle
- Standard calculator with parentheses and mod
- Keyboard support
- Scrollable sections with pinned display
