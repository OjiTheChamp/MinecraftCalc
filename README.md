# ⛏ Crafted Calc

A fully Minecraft-themed scientific calculator by **oji the champ**.

## Minecraft theming
- Sky blue background with pixel clouds
- Grass + dirt ground blocks at the bottom
- Stone block texture on the calculator body
- Green CRT display (like a redstone monitor)
- Buttons styled as Minecraft ore blocks:
  - **Stone** — number keys
  - **Wood planks** — operators
  - **Emerald** — equals
  - **Redstone** — AC (clear)
  - **Lapis Lazuli** — memory
  - **Enchanting purple** — scientific
  - **Diamond** — active DEG/RAD
